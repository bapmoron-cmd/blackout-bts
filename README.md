# BLACKOUT — BTS Maintenance des Systèmes (FEIGE)

Jeu pédagogique basé sur le sujet 2022 Nouvelle-Calédonie, ligne FEIGE.

## Mise en ligne

1. Télécharger `BLACKOUT_FEIGE_V3_LEGER_GITHUB.zip` depuis la conversation ChatGPT et le décompresser.
2. Sur ce dépôt GitHub, choisir **Add file > Upload files**.
3. Déposer **index.html**, **README.txt** et le dossier **assets** (avec toutes les images). Les déposer à la **racine**, et non dans un sous-dossier.
4. Valider via **Commit changes**.
5. Dans **Settings > Pages**, choisir **Deploy from a branch**, **main**, **/(root)**, puis enregistrer.
6. Une fois le déploiement terminé, ouvrir : https://bapmoron-cmd.github.io/blackout-bts/

⚠️ Le fichier `index.html` et le dossier `assets` doivent rester ensemble. Les résultats sont stockés localement sur le navigateur de l'apprenti et ne remontent pas vers un espace formateur.
